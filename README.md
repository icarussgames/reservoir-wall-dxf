# Reservoir Wall DXF

Static Civil 3D helper: Quick Mode takes leftmost/rightmost UTM points, crest width, and slopes, then generates 2D LWPOLYLINE DXF (one elevation per polyline).

## Use

Open the GitHub Pages site, or open `index.html` locally.

## Notes

- Axis: leftmost → rightmost (viewed from upstream in the lake)
- Upstream = left of axis; downstream = right
- Crest borders at ±W/2 (CAD-style offset)
